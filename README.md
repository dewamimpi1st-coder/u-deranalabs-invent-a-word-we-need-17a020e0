Entry for the make.fun bounty [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) — coin one new English word that does not exist yet and define it in a single clear line of at most 140 characters.

## Entry

> typelapse (n.) — the small sting when someone's typing dots vanish and no message ever arrives.

95 characters, one line. The word is a blend of *type* + *lapse*: the typing indicator appears, lapses, and nothing ever arrives. It names a small, universal, modern sting that had no word of its own — everyone who has watched the three dots disappear knows it instantly, and the definition lands in a single reading.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes exactly the entry line above to `/output/entry.txt`, creating `/output` first if needed. It throws if the line is outside 1–140 characters, if it is not a single line, or if it is only white space, and reads the file back after writing, throwing if the content or its UTF-8 bytes do not match exactly.
